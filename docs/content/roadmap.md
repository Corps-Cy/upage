# 功能规划路线图

以下是 UPage 后续版本计划中的功能升级清单，共 34 项，按领域分类。

## AI 能力增强（8 项）

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| 1 | 多模型协作 Agent | 高 | 页面生成 + 审查 + 优化三模型协作，提升生成质量 |
| 2 | 图片参考增强 | 高 | 支持多图输入、图片区域选择、设计稿直接转代码 |
| 3 | 智能补全/续写 | 中 | 输入描述时实时补全，生成中途可暂停编辑后继续 |
| 4 | 页面模板库 | 高 | AI 预生成分类模板（电商、博客、企业官网等），一键套用 |
| 5 | 自然语言编辑 | 高 | "把标题改成红色"、"增加一个轮播图" 等指令式编辑 |
| 6 | 多语言页面生成 | 中 | 描述中指定语言，AI 生成对应语言的页面内容 |
| 7 | SEO 自动优化 | 中 | AI 自动生成 meta 标签、结构化数据、语义化 HTML |
| 8 | 设计系统导出 | 低 | AI 分析页面风格，导出为可复用的 Design Token / Tailwind 配置 |

## 编辑器增强（8 项）

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| 9 | 拖拽排序 | 高 | 组件间拖拽调整顺序，支持跨层级拖入 |
| 10 | 撤销/重做 | 高 | 完整的 undo/redo 栈，支持快捷键 Ctrl+Z / Ctrl+Shift+Z |
| 11 | 组件属性面板 | 高 | 选中组件后右侧显示可编辑属性（颜色、字号、间距等） |
| 12 | 响应式预览 | 高 | 桌面/平板/手机三端实时预览切换 |
| 13 | 代码模式 | 中 | 可视化编辑与源码编辑双模式，实时双向同步 |
| 14 | 组件库 | 中 | 内置常见 UI 组件（按钮、卡片、表单、导航等）可直接插入 |
| 15 | 全局样式管理 | 中 | 集中管理颜色、字体、间距等全局样式变量 |
| 16 | 页面历史版本 | 中 | 保存编辑历史，可回溯到任意版本 |

## 部署能力（7 项）

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| 17 | GitHub Pages 一键部署 | 高 | 自动构建静态版本推送到 gh-pages 分支 |
| 18 | Cloudflare Pages 支持 | 中 | 新增 Cloudflare Pages 部署渠道 |
| 19 | 自定义域名绑定 | 中 | 部署后支持绑定自定义域名 + 自动 HTTPS |
| 20 | 部署状态监控 | 中 | 实时显示部署进度、构建日志、运行状态 |
| 21 | 多环境部署 | 低 | 支持 dev/staging/prod 多环境配置和部署 |
| 22 | 静态导出优化 | 中 | 纯 HTML/CSS/JS 导出，支持 SPA/MPA 两种模式 |
| 23 | Webhook 回调 | 低 | 部署完成后支持 Webhook 通知（钉钉、飞书、Slack） |

## 社交与协作（5 项）

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| 24 | 页面分享链接 | 高 | 生成预览链接，支持密码保护和有效期 |
| 25 | 多用户协作 | 中 | 多人同时编辑同一页面（实时协同） |
| 26 | 评论/批注 | 低 | 在页面任意位置添加评论，支持 @提及 |
| 27 | 版本对比 Diff | 中 | 可视化对比两个版本的差异 |
| 28 | 模板市场 | 中 | 用户可发布自己的页面为模板，他人可复用 |

## 工程化与体验（6 项）

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| 29 | 暗色模式 | 高 | 编辑器和生成页面均支持暗色主题 |
| 30 | 国际化 i18n | 中 | 编辑器界面多语言支持（中/英/日） |
| 31 | 插件系统 | 低 | 支持自定义工具插件（如天气组件、地图组件） |
| 32 | 快捷键系统 | 中 | 完整的键盘快捷键支持，提升编辑效率 |
| 33 | 性能监控面板 | 中 | 显示 AI 调用次数、Token 消耗、响应时间统计 |
| 34 | 离线模式 | 低 | 缓存已生成页面，断网时仍可查看和编辑 |
